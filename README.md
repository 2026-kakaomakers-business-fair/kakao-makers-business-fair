# 카카오메이커스 입점 제안

GitHub Pages에서 화면을 제공하고, 공개 Apps Script 웹 앱에 제출 내용과 첨부파일을 전달해 Google 시트·Drive에 저장합니다. Google 인증정보와 저장 대상 ID는 이 저장소에 포함하지 않습니다.

## 제출 처리

- 첨부파일은 최대 3개, 각각 10MB 이하입니다.
- 숨겨진 폼의 POST 요청으로 전송합니다. 브라우저의 CORS 제한을 우회한 것으로 저장 성공을 추정하지 않습니다.
- Apps Script가 저장을 마친 후 반환한 접수번호가 확인되어야 완료 화면을 표시합니다.
- 응답의 Google 출처, 요청 ID와 매번 발급한 임의 토큰을 확인합니다.
- 실패하거나 120초 안에 결과가 확인되지 않으면 오류를 표시하고 작성 내용을 유지합니다. 같은 요청 ID로 재시도해 서버에서 중복 접수를 방지합니다.
- 제출 처리 중에도 버튼 문구는 `제출하기`로 유지합니다.

## 배포

화면과 배너, 메이커스 탭 아이콘과 공유 이미지는 기존 디자인을 유지합니다. Apps Script 연결 코드를 새 버전으로 배포한 뒤, 첨부파일 저장과 접수 행을 확인하고 GitHub Pages에 반영합니다. Apps Script 배포를 교체할 때는 `assets/submission.js`의 공개 접수 주소도 변경합니다.
