# 카카오메이커스 비즈니스 페어 — 검토용 웹 시안

모바일과 PC에서 입점 제안 화면을 확인하는 정적 사이트입니다.

**현재 실제 입점 제안은 접수하지 않습니다. 입력한 정보와 파일은 서버에 전송하거나 저장하지 않습니다.** 제출하면 예시 완료 화면과 `SAMPLE-0001` 번호만 표시됩니다.

## 파일

- `index.html`: 화면 구조
- `assets/site.css`: 반응형 스타일과 폰트 선언
- `assets/site.js`: 입력 검증과 검토용 완료 화면
- `assets/makers-logo.svg`: 메이커스 사이트의 가로형 로고
- `assets/banner-desktop.svg`, `assets/banner-mobile.svg`: 정적 배너 그래픽

현재 배너 심볼은 사이트 이미지를 참고한 복원본입니다. 실제 운영 전 공식 심볼 에셋으로 교체할 수 있습니다. 배너에는 생성형 이미지 도구로 제작한 흑백 워프 배경이 포함됩니다.

## GitHub Pages

1. 이 파일들을 저장소 루트에 업로드합니다.
2. 저장소 Settings → Pages에서 Deploy from a branch를 선택합니다.
3. 업로드한 브랜치의 `/ (root)`를 게시 대상으로 지정합니다.
4. GitHub가 표시하는 사이트 주소로 접속합니다.

GitHub Free의 Pages는 공개 저장소를 사용합니다. 공개 범위 및 업무용 사용 조건을 확인한 뒤 게시합니다.

## 실제 접수로 전환할 때

Google Apps Script 등 접수 처리 기능을 구현하고, 비공개 Google Sheets 및 첨부파일 저장 공간에 연결해야 합니다. 저장 성공 응답을 받은 뒤 완료 화면을 표시해야 하며, 운영자의 조회 권한과 90일 자동 파기 일정도 별도로 구성해야 합니다.

이 저장소에는 신청 내역, 개인 연락처, 인증정보, 내부 호스팅 설정 및 이전 시안을 포함하지 않습니다.
