# 카카오메이커스 비즈니스 페어 입점 제안

GitHub Pages 버전은 입력부터 접수 완료 화면까지 확인하는 미리보기입니다. 입력 내용과 첨부파일은 전송하거나 저장하지 않습니다. Google 인증정보와 외부 접수 주소도 포함하지 않습니다.

Apps Script 버전과 행사명, 배너, 입력 항목, 개인정보 안내 표, 제출하기 버튼, 접수 완료 화면을 맞췄습니다. 제출 중에도 버튼 문구는 제출하기로 유지하고 중복 클릭은 막습니다.

미리보기 접수번호는 MK-YYYYMMDD-0001 형식이며 날짜는 한국 시간 기준입니다. 마지막 숫자는 열린 페이지 안에서만 증가하는 예시로, 새로고침하면 초기화됩니다. 실제 접수번호가 아니며 서버의 접수 이력과 무관합니다. 미리보기에는 하루 1,000건 제한이 없습니다.

실제 저장을 제공하는 Apps Script 배포는 별도로 관리합니다. GitHub 버전의 실접수는 저장 연결, 서버 순번 발급, 중복 요청 처리와 저장 성공 응답 확인을 구현한 뒤 활성화해야 합니다.
