# 카카오메이커스 비즈니스 페어 입점 제안

모바일·PC에서 작성할 수 있는 GitHub Pages 사이트입니다.

제출 시 Make를 거쳐 운영자의 비공개 Google Sheets에 저장합니다. Google 로그인은 필요하지 않으며, 저장 성공 응답을 받은 뒤 접수 완료 화면을 표시합니다. 자료는 공유 링크 또는 상품 URL로 받습니다. 파일 직접 업로드는 현재 지원하지 않습니다.

- index.html: 화면 구조
- assets/site.css: 반응형 디자인과 폰트
- assets/site.js: 입력 검증과 접수 화면
- assets/submission.js: 실제 저장 연결과 응답 확인

Google 인증정보와 접수 내역은 저장소에 포함하지 않습니다. 수신 URL은 공개 주소이며 비밀 인증키가 아닙니다. 개인정보 동의와 필수 입력값은 수신 측에서도 확인합니다. 시트를 공개하지 않습니다.

Make 시나리오는 즉시 실행 방식으로 활성화되어 있어야 합니다. 무료 플랜의 처리량과 오류 이력은 운영자가 Make에서 확인합니다. 네트워크 시간 초과 시 저장되었을 수 있으므로 안내된 접수번호로 확인 후 재접수합니다. 서버 측 중복 제거는 아직 지원하지 않습니다.

90일 보유기간 정리는 기존 회사 Apps Script의 정리 작업을 사용합니다. Make의 별도 실행 로그와 큐 보존 정책도 운영 시 관리해야 합니다.

배너 심볼은 사이트 이미지를 참고한 복원본입니다. 배너에는 생성형 이미지 도구로 제작한 흑백 워프 배경이 포함됩니다.
